# Signalpost project status

The current code passes 59 automated tests, including a mocked 1,000-company batch. A live 100-company run returned 100 terminal profiles in 95,067 ms, using 314 requests. All 100 BRREG identities and role lists were available; finance data was available for 99 companies, with one source HTTP 500. Website and vacancy coverage remained sparse. The run made no paid provider calls. Exact counts and limitations are recorded in [QA_TEST_REPORT.md](QA_TEST_REPORT.md), and its local judge assessment is in [SIGNALPOST_JUDGE_REPORT.md](SIGNALPOST_JUDGE_REPORT.md).

The finance adapter now follows BRREG's documented organization-number path. Website fetching uses a hostname-pinned HTTPS connection and keeps TLS hostname verification enabled. Website activity extraction checks dated same-company news links; optional LLM web-search citations remain unverified until the cited page's quote, identity and date are fetched and matched. The five reference projects have pinned revisions and isolated checks in [REFERENCE_EVALUATION.md](REFERENCE_EVALUATION.md); only the BRREG type validator received a direct behavioral smoke check, while test suites for other projects were blocked by missing test dependencies or API credentials.

Builderr's current page requires a 100-company smoke test/report; it does not require 1,000 precomputed company profiles. The local 1,000-company test is fixture-backed. This GitHub push publishes code and test evidence; it does not submit the project to Builderr or establish a Builderr score or qualification. The official evaluator controls the score against its checked collection.
